# belly-button-challenge
## Repository Contents

- `index.html`  
  The main HTML file for the dashboard. Open this file in a browser or view the deployed version online.

- `app.js`  
  Contains the JavaScript logic for loading data, building charts, and handling user interactions.

- `samples.json`  
  Provided as a reference to understand the structure of the dataset (the live site uses a hosted version).
